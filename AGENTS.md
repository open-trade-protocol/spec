# Protocol Spec — Agent Instructions

## Архитектура
- `openapi/` — OpenAPI 3.1 спецификации
- `schemas/` — JSON Schema
- `contexts/` — JSON-LD контексты
- `protocols/` — RFC-подобные документы протоколов

## Правила
- Все спецификации должны быть валидными (проверяйте через `spectral lint`)
- Используйте semantic versioning (0.1.0, 0.2.0)
- Изменения требуют RFC-процесса в будущем
